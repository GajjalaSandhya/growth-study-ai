# Phase 11 — Frontend ↔ Backend Integration Matrix

This document provides a complete, itemized mapping matrix linking every frontend route and API method to its corresponding Phase 1–10 backend REST endpoint, compatibility status, and exact required integration work.

## Compatibility Status Codes

- **STATUS A — EXACT MATCH**: Backend endpoint exists and data structure matches directly.
- **STATUS B — MAPPING REQUIRED**: Backend endpoint exists; frontend field names or wrapper objects require mapping.
- **STATUS C — FRONTEND FEATURE HAS NO BACKEND SUPPORT**: Frontend expects feature not supported in Phase 1–10 backend.
- **STATUS D — BACKEND CAPABILITY HAS NO FRONTEND UI**: Backend feature exists but frontend has no UI trigger.
